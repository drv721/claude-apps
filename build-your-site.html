Step by step

1

Design the page in Claude Design

Go to claude.ai/design. Click + Create, select High Fidelity, and paste a prompt describing what you want. This works exactly like prompting ChatGPT — except the output is a visual design instead of text.

Prompt example — customize this for your site

Create a coming soon landing page for [yoursite.com]. [Color] color scheme. Clean, minimal. Headline: "[Your headline]." Subheadline: "[Your tagline]." Include an email signup field and a brief description: [One sentence about what you do and where you're based].

Claude Design generates a live mockup. Use the Tweaks panel to adjust things like light/dark mode. When you're happy, export it as an HTML file.

Canva user? Design in Canva instead and export it. GitHub and Cloudflare don't care where the file came from — the rest of the steps are identical.
2

Store it on GitHub

Go to github.com and create a free account. Make a new repository (think of it as a project folder) named after your site.

  1. Click Add file → Upload files
  2. Drag in the HTML file from Claude Design
  3. Rename it index.html
  4. Click Commit changes

That's it. Your file is saved to the cloud.

3

Connect GitHub to Cloudflare Pages

Go to cloudflare.com and create a free account. Then:

  1. Go to Workers & Pages → Create → Pages → Connect to Git
  2. Select your repository
  3. Click Deploy

Cloudflare gives you a live URL immediately. From this point on, any time you update index.html on GitHub, the site updates automatically within seconds — no re-deploying needed.

4

Point your domain at it

In Cloudflare, go to your domain's DNS settings and delete any existing A records (these are leftover from wherever you registered the domain — GoDaddy, Namecheap, etc.).

Then go to Pages → Custom Domains and add your domain. Done — your site is live at your real address.

How this compares to Squarespace

Tool What it does Squarespace equivalent
Claude Design Designs and exports the page Squarespace's drag-and-drop editor
GitHub Stores every version of your files Squarespace's auto-save
Cloudflare Pages Hosts and publishes the site Squarespace hosting

Squarespace bundles all three in one dashboard. This approach keeps them separate — but each piece is free or nearly free, and you own the actual code rather than renting a template.

Want more than a landing page?

A landing page gets you live fast. When you're ready to add more, Claude can build it — just give it one of these prompts.

🧭 Navigation menu (multiple sections)

Adds a top nav bar with links that scroll to different sections of your page.

Give Claude this prompt

I have an existing homepage called index.html. Add a navigation bar at the top with links to: Home, About, Services, and Contact. Each link should scroll to a section on the same page. Match the existing color scheme and keep the design minimal.

✉️ Contact form

A form visitors can fill out. Claude can build the design now; connecting it to actually send you emails takes one extra step using a free service called Formspree.

Give Claude this prompt

Add a contact form to my site with fields for name, email, and message. Include a Submit button. Connect it to Formspree so submissions arrive in my email at [your@email.com]. Match the existing design.

🛍️ Sell products or services

For real e-commerce (cart, checkout, payments), the easiest path is letting Shopify or Gumroad handle the store — then Claude embeds a buy button into your site.

Give Claude this prompt

I want to sell [products] on my site. I already have a Shopify store at [your-store.myshopify.com]. Add a Shop section to my homepage that shows my three featured products and links to the store to complete checkout. Match my existing design.

📝 Blog or content section

A section that shows your most recent posts as cards — title, date, and a short description. You update the content manually each time.

Give Claude this prompt

Add a blog section to my homepage that shows the three most recent posts as cards with a title, date, and short description. I'll update these manually. Match the existing design and keep it minimal.

📅 Booking / scheduling

Embed your Calendly directly into the page so visitors can book time without leaving your site.

Give Claude this prompt

Add a Book a Call section to my site. I use Calendly at [your-calendly-link]. Embed the Calendly widget so visitors can schedule directly from my site without leaving the page.
